# Cartography

**Summary**: Notes on map making and GIS software for designing, editing, analyzing and sharing maps.
**Last updated**: 2026-11-18

---

- [QGIS: Spatial without Compromise](https://www.qgis.org/): QGIS is free and open-source desktop GIS (GPLv2+) for making maps, editing and digitizing layers, running spatial analysis in its processing toolbox, and publishing maps in many formats. It is community-driven and also supports 3D. It can be driven by Claude Code through the QGIS MCP server (see [[Agentic_Coding]]). *Keywords*: QGIS, GIS, open source, map design, digitizing, spatial analysis
